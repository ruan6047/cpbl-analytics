## 4. 真正的判準不是「故四」，是「島內有沒有結果敘述列」

卡面把問題框成「故四」，但**故四既不是充分也不是必要條件**：

- A/240 第 9 局的同一個打席序列同時產生兩個零投球島：
  - `0910012000` 掛**林岱安**、`content = 教練暫停` → **真幽靈島**，官方不計（官方 PA 3 ＝ 我方 3）。
  - `0910013000–0910014000` 掛**胡金龍**（`更換代打：林岱安=>胡金龍` ＋ `故意四壞球上壘。`）
    → **真打席**，官方計（官方 PA 1 ＞ 我方 0）。
- A/151 林吳晉瑋的「雙殺」島（`教練暫停` ＋ 打擊結果敘述、無投球旗標列）也是真打席，官方計。

以官方逐場 box 為 ground truth（`official_extra = 官方 box PA − 我方計入島 PA`），
在 **2025 A/D 全部 442 個含幽靈島的 (場次, 打者)** 上比對三個候選判準：

| 判準 | 命中 (場次,打者) 對 |
|---|---|
| `has_result_row`（島內存在非「更換／教練暫停／抗議／裁判」的 content 列） | **442 / 442** |
| `is_ibb`（卡面的窄口徑：結果詞彙＝故四） | 440 / 442 |
| `in_canonical_pa`（canonical PA builder 自己的判定） | 382 / 442 |

**但此判準不可外推為普適**（跨年重測後才敢這樣說）：2018–2026 A/D 共 3,466 對，
`has_result_row` 命中 **3,456 / 3,466**，10 個不命中逐對列在 `_IMPACT.json`
`criterion_mismatches`——9 個偽陽性（判準說是真打席、官方不計，結果詞彙為
三振×3／二飛×2／四壞×2／死球／犧短）、1 個偽陰性（2023 A 第 99 場，故四島無結果敘述列

## 6. RECALC1「全命中」前提重驗（卡面驗收第 3 項）

卡面給了三種可能，實測落在**第二種**，並且需要修正前提的敘述：

> **判定：官方計入，但 RECALC1 的 grid 未涵蓋那些格 → 宣稱範圍要收窄。**

- 涵蓋率實查（`_RECALC1.json`）：20 組受影響 (賽別, 打者) 共 **63 個受影響格，
  其中只有 3 格出現在 RECALC1 的 2,435 列 grid 內**（60 格不在）。
- 更根本的一點：**該 grid 從來不是與官方值的對照**。
  `scripts/reconcile_splits_recalc1.py` 的 `expected` 讀
  `ingest_splits_pa_split1_player_delta.json`，其 `note` 自述
  「corrected＝legacy＋僅合併 counted 缺陷邊界」——**legacy 與 corrected 兩端都是我方
  自己算的**。17,997 格驗的是「重建能否逐格重現先前已查核的修正量」，
  屬**可重現性／冪等性**檢查，不含任何官方數值。
  RECALC1 卡面第 60 行的原文也是「**預期 delta** 17,997 格全數命中」，
  本卡卡面轉述為「**官方值** 17,997 格全命中」時放大了它的宣稱範圍。
- 因此**兩者之間沒有矛盾需要解消**：RECALC1 的結論在其真正的範圍內仍然成立，
  它只是從未檢驗過官方分項的絕對值。那 3 格重疊也不構成反證——它們之所以在 grid 裡
  是因為 PA-SPLIT1 的代打誤切修正動到它們，與幽靈島無關。

> 這是記憶 `rule-premise-and-reconciliation-limits`「窮舉對帳零例外只證一致性，
> 不驗前提真假」的第三個實例：對帳全綠、程式冪等、而絕對值錯了 281 席。
