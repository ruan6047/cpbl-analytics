## 1. 驗收條件①：同母體 calibration 不能作為時間外證據（已證明）

同一套評估框架（canonical PA、同分箱、同 cluster bootstrap）下，生產 artifact（`cpbl.run_dist` span 2018-2025/A，即已上線模型）：

| 評估母體 | ECE | 十分位 1/2/3 偏差 | 十分位 8 | 顯著分箱（99% CI 排除 0） |
|---|---|---|---|---|
| **同母體 in-sample**（2018–25 對建模母體自身，2,335 場） | **0.0147** | +1.0 / +2.0 / +1.6pt（CI 全含 0） | −2.8pt（顯著） | [8, 9] |
| **時間外 walk-forward 池化**（2021–26，各季模型 span ≤ Y−1） | **0.0260** | **+4.2 / +5.3 / +6.0pt（全顯著）** | **−4.3pt（顯著）** | [1, 2, 3, 8, 9] |

三個層次的證明：

1. **同母體評估看起來可接受**（ECE 1.5%、低分箱無顯著偏差）——與上線時「校準 1–3pt」的結論一致。它不是算錯，而是**結構上看不到時間外會發生的事**。
2. **低分箱 +4~6pt 偏差只在時間外出現**：主因是主場優勢漂移（訓練窗 2018–20 主隊勝率 0.562 → 2021 起 0.52–0.54）。池化同母體把「用當季資料評當季」的自我吸收平均進去，漂移被構造性抹掉。
3. **逐季 in-sample Brier 樂觀偏差極小**（0.00002–0.0017）：run_dist/WE 是低變異估計器，「訓練集重用」不是主要問題——**逐季分布漂移與跨季池化平均**才是。這排除了「多留幾季 holdout 就好」的簡化想像：必須逐季 walk-forward。

另一個同母體證據失效的結構性原因：**2024 起延長賽突破僵局制**（聯盟規章第 37 條，113 年修定）改變了延長局狀態機。含 2024+ 的池化同母體校準對「新規則下的延長局」完全沉默（延長打席僅佔 ~1–2%，池化指標無感），walk-forward 分季才看得到。

## 2. 方法

沿用 `models/winprob.py` 現行方法（run_dist 半局剩餘得分分布 + WE 邊界 DP），僅做本卡所需的兩件事：

1. **打席單位改消費 GAME-RECAP-PA1 canonical 打席**：`cpbl.game_plate_appearances`（published build、`state='ready'`）的 `pre_state` 直接作為 WP 評分狀態；訓練快照機器沿用 livelog（與生產一致）。
2. **時間切分**：驗證季 Y 的模型只用 2018..Y−1 訓練（記憶體內重建分布，**全程唯讀**，不寫 `run_dist`/`win_expectancy`）。C/E 的代理模型訓練窗含當年例行季（季後賽開打前例行賽已全數完成，時間上無洩漏）。

**訓練管線等價性對帳（match）**：記憶體快照機器以 2018–2025/A 窗口重建的分布與生產 `cpbl.run_dist` **48 個狀態逐列相等**（`counting_machine_check: match`）。因此 walk-forward 與生產結果的差異只能歸因於時間切分，不是實作漂移。解算器另以離線測試證明 legacy 規則下與生產 `_we_solver`/`wp_state` 逐值相等（`tests/test_winprob_val.py`）。

**統計檢定**：同場打席共享同一賽果 → 有效樣本 ≈ 場數（單季僅 150–360 場）。所有分箱偏差以 **game-cluster bootstrap**（整場重抽 500 次）估 SE 與 99% CI；十分位偏差的單季雜訊底線即 ~3pt。判定主力放在池化 walk-forward（A：1,826 場，檢定力 ~10 倍）。

**偏差結構解讀**（S 型，各季方向一致）：

- **十分位 1–3（落後中的主隊被高估 +4~6pt）**：主場優勢漂移主導（時間外才可見，同母體僅 +1~2pt 不顯著）。
- **十分位 8–9（領先中的主隊被低估 −3~4pt）**：**結構性**——同母體 in-sample 亦顯著（−2.8pt）。中性隊伍假設的代價：現實中領先方不成比例地是較強隊（先發好投在投、戰力差），局面 DP 不知道，於是低估領先的持續性。`winprob.py` 天花板揭露早已聲明此假設；本驗證第一次量化其成本並證明統計顯著。
- 產品語意影響：這兩端正是「翻盤敘事」與「勝券在握」的打席——**對 recap 產品最重要的區段偏差最大**，不能靠「中段還算準」帶過。

### 3.2 D 二軍例行（驗證 2021–2026）

逐季 ECE 0.023–0.052、maxdev 0.056–0.116（單季雜訊底線內外參半）；池化（1,151 場 / 87,948 打席）ECE 0.019，**十分位 2 偏差 +4.7pt 顯著超界** → unsupported。結構背景：二軍主隊勝率逐年滑向 0.50（2018–24 訓練窗 0.513–0.530 → 近年 ~0.50，且多場館中立性高），主場結構不穩定使跨年分布聚合失真。

### 3.3 C 一軍季後（代理：A 分布 + C 規則）

全期僅 25 場（1,930 打席）。池化 ECE 0.110 > 0.05 代理門檻 → unsupported。除樣本不足外有**已知系統性混淆**：季後主隊指定與種子強度掛鉤（挑戰賽高種子多主場＋讓一勝），中性隊伍＋主場優勢模型的失效方向可預期（2025 年 5 場主隊實際勝率權重僅 0.18，模型預測 ~0.44–0.49）。單季 n=4–7 場永遠不足以逐季驗證；解鎖需種子/戰力感知模型（§7）。

### 3.4 E 二軍季後（代理：D 分布 + E 規則）

全期 13 場。E2025 Brier 0.289 **輸給**主場常數基準 0.250（硬性失敗）；2022/2024 主隊全勝（分箱 actual=1.0）凸顯樣本荒謬性。unsupported，短期無解鎖路徑。

## 5. Go/No-Go 門檻（v1 → v2 修訂與理由）

**v1（首輪預註冊）**：逐季點估計 ECE ≤ 0.025、maxdev ≤ 0.06。首輪結果全 scope 超標後，檢討發現 v1 **在統計上先天有缺陷**：同場打席共享賽果（叢集相關），單季有效樣本≈場數（150–360），十分位偏差抽樣雜訊底線即 ~3pt——ECE 0.025 門檻低於單季雜訊底線，**校準完美的模型也會經常超標**（離線測試 `test_cluster_bootstrap_wider_than_iid_for_correlated_games` 固化此事實：叢集 SE > 3× 天真逐 PA SE）。

**v2（判定採用）**：
- 硬性失敗 → unsupported：任一季 coverage < 0.98；任一季 Brier 未勝主場常數基準；池化 walk-forward 十分位（n≥1000）|偏差| > 0.03 且 99% cluster CI 排除 0；proxy scope 池化 ECE > 0.05。
- proxy 上限：C/E（借分布）與全季小樣本 scope 最高 proxy_with_warning。
- 其餘 supported；顯著但 ≤3pt 的偏差列 disclosure。

v1 逐季點估計全數保留在 artifact 與本報告（§3 表）供稽核；**v2 並未放寬結論**——最終判定（全 unsupported）比 v1 更嚴謹且更有解釋力。修訂過程完整留痕，供跨家族查核者檢視「是否移動門檻遷就結果」：v2 的池化判準比 v1 的逐季點估計檢定力更高、更難靠雜訊過關。

## 7. WP-API1 解鎖條件（本卡輸出的後續門檻）

任一路徑完成後**重跑本 harness**（指令見文首），以 v2 門檻重新判定；通過的 scope 才解除 `GAME-RECAP-WP-API1` 對應範圍：

1. **A（最短路徑）— 事後校準層**：對 walk-forward 預測擬合單調校準（isotonic / beta calibration），**校準器本身亦須時間外驗證**（於 Y 季擬合、Y+1 季評估）。S 型偏差各季方向穩定（§3.1），此路徑預期可行。
2. **A（治本）— 戰力感知**：局面 WP 疊加隊伍強度/先發投手先驗（貝式收縮或以 outcome 模型先驗為 anchor），消除領先持續性低估的結構根源。工作量大，另開卡。
3. **C**：需種子/讓一勝感知的季後賽專用先驗；單季樣本永遠不足，驗證設計須跨季池化 + 預註冊方向性檢定。
4. **D**：主場結構逐年重估（或以近年窗訓練）後重驗；**E**：無樣本路徑，建議長期 unsupported。
5. 產品過渡決策（需求方裁定，非本卡範圍）：賽況頁既有 WP 曲線是否加註「局面勝率，未含戰力差；領先/落後端有 ±4–6pt 已知偏差」的說明。
