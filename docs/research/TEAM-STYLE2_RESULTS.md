### 0.2 逐季主教練判定規則（凍結）

**資料源**：zh.wikipedia 六隊 franchise 條目（條目對映沿用
`src/cpbl/ingest/cpbl_managers.py` 的 `WIKI_TITLE`），以 MediaWiki parse API 抓取一次並
**快照落檔** `docs/research/team_style2_wiki_snapshot.json`（含 page revid＋抓取時間＋
展開後原始列）；分析一律讀快照，確保查核者重跑逐位一致、不受維基後續編修影響。
**全程不寫任何 DB 表。**

**表格選定與展開**（重用 `cpbl_managers` 既有解析，不另立口徑）：

1. 每條目取「含『姓名/總教練』欄＋『勝(場)』欄、列數最多」的表（`_best_table` 同款）。
2. rowspan 依 `_parse_managers` 同款網格展開邏輯還原完整列。
3. 結構偵察已查定：**六隊此表皆為逐年列＋逐列出賽數**（含中信「按總教練分」專表
   亦為逐季列；季中換帥年為多列、各帶該任場數）。

**季 y 的主教練判定（機械規則，逐條凍結）**：

1. 候選列 = 展開後年份欄**第一個四位數字 = y** 且「出賽」欄可解析為正整數的列
   （統一式「2019上半季」「2022/05/17-5/24」年份欄照此規則取 2019 / 2022）。
2. 姓名取「姓名/總教練」欄經 `_clean_name`（去括號註記）後字串；空白與
   合計類（`--`、`—`、`-`、`合計`、`總計`、`小計`、`累計`）列排除。
3. 同季同名多列（同季多任次）場數**加總**。
4. **主教練 = 該季場數唯一最大者**（卡面規則「執教場數最多者」的機械化）。
5. **平手（最大場數非唯一）→ 該季「不可判定」**。代理（「代」「(代理)」）不做
   特殊處理、一律按場數比——這是卡面規則的直接推論，不引入頭銜式 tiebreak。
6. 防禦性規定（偵察未見、仍先凍結）：單列姓名欄含多名（頓號/斜線分隔）→ 不可判定；
   某季無任何含場數列 → 不可判定。
7. **`to_year` 紅線**：判定**不使用** `managers.g`（任期總計）、不使用
   from_year–to_year 範圍推論（to_year＝維基最後戰績列年份、非卸任年）；
   逐季場數一律出自逐年列。偵察查定六隊皆有逐年列，故卡面預留的
   「無逐年列者以任期年份範圍判定」分支**實際不會觸發**；若快照解析意外落入
   無逐年列情境，該季一律「不可判定」，不退回範圍推論。

**預告（偵察已見、規則將機械複現）**：統一 2019 為 黃甘霖 60 場（上半季）／
劉育辰 60 場（下半季，代理）**平手 → 不可判定**，預期排除配對
ADD011 2018→2019 與 2019→2020 兩組；其餘 31 組預期皆可判定。實際以規則跑出為準，
排除清單逐列窮舉於 artifact。

**QA 交叉檢核（非判定依據；DB 唯讀 SELECT）**：每一判定出的
(franchise, y, 主教練) 應存在 `cpbl.managers` 列滿足 `team_code=franchise AND
name=主教練 AND from_year ≤ y ≤ to_year`（y ≤ 2025 時 to_year ≥ y 應成立，因維基
逐年列已含該年）。不符者於 artifact 列 mismatch 並照實報告，**不回改判定**。

### 0.3 配對二分規則（凍結）

- **同教練組**：main(t) 與 main(t+1) 皆可判定，且清理後姓名字串完全相等。
- **換教練組**：皆可判定且不相等。
- 任一季不可判定 → 該配對**排除**，逐列窮舉於 artifact（含排除原因）。
- 33 組配對的歸屬（含 t / t+1 主教練姓名、判定依據之原始列）逐對窮舉於 artifact。

### 0.4 統計量與判讀（凍結；先於計算寫死）

1. **逐軸兩組 r**：每軸、每組內，配對的 (z_t, z_{t+1}) Pearson r，連同配對數 n 報告。
2. **逐軸差異** Δr_axis = r_same − r_changed。
3. **池化差異** Δ̄ = 七軸 Δr_axis 的**不加權平均**（軸皆為季內 z、同尺度，
   不加權平均為最透明的池化方式；不採 stacked 池化以免跨軸均值效應混入）。
4. **Bootstrap（配對層 cluster 重抽）**：
   - 兩組**各自分層**重抽（含放回；重抽樣本數維持各組原 n；一配對之 7 軸整包跟著走）。
   - B = 10,000；RNG = `numpy.random.default_rng(20260727)`；每 replicate 重算全部
     Δr_axis 與 Δ̄。
   - CI = percentile 95%（2.5 / 97.5 百分位），報告 Δ̄ 與每軸 Δr_axis 的 CI。
   - 退化保護：replicate 內若某組某軸 z 向量標準差為 0（Pearson r 未定義），
     該 replicate 整筆剔除並於 artifact 計數（連續 z 值下預期 0）。
5. **結論判準（Go/No-Go，先寫死不得算完再定）**：
   - **Go（任期分段成立）⇔ (i) 至少 4/7 軸 Δr_axis > 0（方向一致性），且
     (ii) Δ̄ 的 95% bootstrap CI 下界 > 0（池化差異排除 0）。**
   - 兩條件任一不滿足 → **No-Go**：維持逐季呈現；教練分段僅可作為呈現選項
     （事實分組）不得作風格延續性宣稱。
   - **|Δr| 點估計不得單獨作結論**；CI 含 0 即 No-Go，無論點估計多大。
6. **小樣本誠實聲明**：偵察格式推估兩組約 20 / 11 對（實際以規則跑出為準；
   卡面預期 15–18 對係假設排除較多）。n≈11 的單軸 r 抽樣誤差極大，
   逐軸數字僅作描述性參考；結論僅依上述池化判準。
