## 1. 問題與協定

STRENGTH1 No-Go 根因是八項賽前特徵時間外無增量資訊；其執行期 scratch 曾見
bio 三項有效但屬選型洩漏（看過結果後評估），本卡做乾淨重估。協定全文見預註冊
spec；重點：母體與 STRENGTH1 同（kind A 完成場、`data_as_of=2026-07-27`，逐季
場數逐場對帳相等）、七項特徵凍結（隊伍四項直接沿 STRENGTH1 loader 的
`team_feats`；bio 三項＝先發年紀差／身分差／年資差，賽前可得推導見 spec §2–§5）、
L2 logistic λ=100 不掃網格、bootstrap reps=10000 / seed=20260727 / percentile 99%。

賽前可得規則（卡面凍結）：身分用 `cpbl.imports.classify` canonical 判定
（含羅力／永田條款；二值化 {import, loree}→1）；年資用 `pitching_seasons`
嚴格早於比賽年的首見年（不用 `players.debut`，覆蓋僅 65%）；生日缺值 fail-closed
＝fit 窗聯盟均值中性填補（不排除場次），逐年計數見 §4。

## 3. 三判準逐條（spec §6 凍結定義；未捨入值判定）

1. **C1 池化 Brier 優於主場常數**：0.240666 < 0.245949 → **PASS**。
2. **C2 池化 99% 逐場 bootstrap CI 排除 0 且方向為改善**：CI = [−0.009116, −0.001548]，
   上界 < 0 → **PASS**。
3. **C3 2026 不得顯著反向**（凍結定義＝點估計 > 0 且 99% CI 下界 > 0）：
   Δ(2026) = +0.006116 > 0，但 CI = [−0.004094, +0.016480] 含 0 → 非顯著反向 →
   **PASS，帶方向警訊**（spec 要求揭露：2026 年至今 219 場，樣本尚小，
   點估計方向與 2023–2025 相反，與開卡時 scratch 警訊一致）。

三項同時成立 → **過關（Go）**。

## 4. 母體對帳與揭露（完整性窮舉；artifact `population`）

- 逐年完成場（獨立 SQL）＝實際評分場（loader），2018–2026 全等：
  239／240／240／299／300／298／360／359／219（驗證季 2023–2026 合計 1236，
  與 STRENGTH1 artifact 逐季 `n_val_games` 相同）。
- 生日缺值：全母體僅 **2025** 受影響——14 位先發缺生日，144 場／164 席次
  以 fit 窗（2018..2024）均值 29.74 歲中性填補；其餘年份 0。
- **已知資料缺陷（不改協定、誠實揭露）**：該 14 位缺生日先發**同時缺 country**
  （皆 2025 短期洋將，音譯名），canonical `classify` 對 NULL country 保守回
  `local` → 2025 有 144 場身分特徵被標為本土。此偏差**壓低** 2025 的
  `starter_import_diff` 訊號，2025 Δ = −0.008404 是在此不利偏差下取得；
  修補 country／birthday 是資料清理卡的事，本卡照凍結協定執行。
