## 0. 結論（Go/No-Go）

**A scope（一軍例行）＋單調事後校準層：unsupported（No-Go）。`GAME-RECAP-WP-API1` 的 A 範圍維持阻塞。**

| 門檻（卡面預先固定，未修訂） | 結果（判定族：beta；isotonic 對照同向） |
|---|---|
| 池化（2023–26）十分位 n≥1000 \|dev\| ≤ 3pt 或 99% 叢集 CI 含 0 | ✅ **通過**（校準後 0 個顯著分箱；base 同池化有 bin 7 −4.9pt 顯著超界） |
| 每季 Brier 勝主場常數基準 | ✅ 通過（4/4 季，幅度 ~0.08–0.10） |
| 每季 Brier 不得劣於未校準 base | ❌ **2023 劣 +0.00002（雜訊尺度）、2026 劣 +0.00075（超出捨入雜訊）** |
| coverage ≥ 0.98 | ❌ **2026 = 0.9722**（PA build 落後 6 場，資料工程缺口非模型缺陷，見 §6） |
| 逐局帶（1-3/4-6/7-9）相對 base 不得系統性惡化 | ❌ **1-3 帶 \|dev\| 0.1pt → 2.6pt（惡化 +2.5pt > 2pt 硬性上限）**；4-6 帶 +1.0pt 揭露 |

> 與 WP-VAL1 相同的注解適用：Brier 全面大勝常數基準——**問題不在辨別力而在校準**，且本卡證實
> 池化分箱層級的 S 型偏差確實可被單調校準壓平（第一列 ✅）。No-Go 的決定性證據是**校準修正本身
> 不具時間平穩性**（§5）：對 2023–26 驗證季，校準器從 2021–22 wf 對學到的「中心下修」已過時，
> 反而系統性破壞原本近乎完美的早局帶。此失效**只有嵌套時間外驗證看得到**——若照天真做法
> 「池化全部 wf 對→擬合→上線」，內部指標全數支持（§2），會把有害的校準層直接推上生產。

三條硬性失敗中，即使剔除 2023 的雜訊尺度差距與 2026 的資料工程 coverage 缺口，1-3 帶系統性
惡化與 2026 Brier 退化仍獨立成立——結論不是壓線判負，不適用「接近門檻」放行（卡面驗收條件）。

## 1. 方法與嵌套時間分離（紅線落實）

實作：[`src/cpbl/models/winprob_cal.py`](../../src/cpbl/models/winprob_cal.py)，全程復用
`winprob_val` 的 walk-forward 管線（同快照機器、同解算器、同指標與 game-cluster bootstrap，
seed 20260725），**全程唯讀**。逐季 base wf 預測與 WP-VAL1 §3.1 逐位一致
（2023–26 base Brier 0.14745/0.15388/0.15448/0.16612 = VAL1 報告值），等價性由此錨定。

| 紅線 | 落實 |
|---|---|
| 校準器只用時間外 wf 預測擬合 | `calibration_pairs()` 是唯一取數入口，只吐 s < Y 的 wf 對（該預測由 span ≤ s−1 的 base 產生）；runner 另 assert 每季 span ≤ s−1；合約測試固化 |
| 嵌套時間分離 | 驗證季 Y ∈ {2023..2026}；校準窗 = [2021, Y−1] 的 wf 對；base 窗 = [2018, s−1]。三者皆 ≤ Y−1 |
| 單調、[0,1]、端點 | 兩族皆單調且 f(0)=0、f(1)=1（終場收斂語意保持；單調映射不改變再見門檻跨越次序）。isotonic：等量分箱（每箱 ≥500 PA、≤50 箱）+ 加權 PAV + 端點釘——即卡面要求的段數/樣本下限尾端防護；beta：logit(q)=a·ln p−b·ln(1−p)+c，a,b>0 硬約束 |
| 判定沿用 v2 門檻 | `pooled_bin_dev_max=0.03`、`min_coverage=0.98`、`boot_ci=0.99` 直接 import 自 `winprob_val.THRESHOLDS`；新增門檻（劣於 base、逐局帶）跑驗證前預註冊於 `CAL_THRESHOLDS`（合約測試鎖定數值，改動即紅） |
| 選型不得用驗證季 | §2；選型窗（fit 2021 → eval 2022）全體早於首個驗證季 2023 |

校準訓練對含 irregular 場（與主評估母體一致；WP-VAL1 §4 同語意）。和局結果 0.5 對
isotonic（加權均值）與 beta（Bernoulli log-loss 的分數標籤）皆為 proper 處理。
兩族擬合皆決定性（無 RNG；輸入先排序 → 與 DB 列序無關，合約測試驗證逐位重現）。

## 2. 選型（只用校準訓練窗內指標；先於驗證鎖定）

內部前向評估：fit 2021 wf 對（23,000）→ eval 2022 wf 對（22,847）。

| 族 | 內部 Brier | 內部 ECE | 參數 |
|---|---|---|---|
| base（無校準） | 0.14740 | 0.04628 | — |
| isotonic | 0.14504 | 0.02195 | 39–46 段（逐驗證季窗） |
| **beta（選定）** | **0.14466** | 0.01682 | a≈1.0、b≈1.44、c≈−0.47（逐窗詳 artifact） |

決策規則（程式碼預註冊）：內部 Brier 低者勝（差 ≥1e-5），同分比 ECE，再同分取低複雜度。
beta 以 Brier 0.14466 vs 0.14504 勝出 → **判定視角固定為 beta**；isotonic 全程並排回報作對照。
注意：內部窗證據強烈支持校準（Brier −0.0027、ECE 0.046→0.017）——這正是天真流程會上線的依據；
失效在驗證季才顯現（§5）。

## 4. 門檻判定逐條（判定族 beta）

硬性失敗（任一即 unsupported）：

1. **A2023 校準後 Brier 0.14747 > base 0.14745**（+0.00002，捨入粒度 1e-5 之上但屬雜訊尺度；
   門檻嚴格執行不得放寬，如實記錄）。
2. **A2026 校準後 Brier 0.16687 > base 0.16612**（+0.00075，超出雜訊尺度；isotonic 更差
   +0.00113——最新、校準最好的 base 模型被過時修正拉低，§5 機制的直接證據）。
3. **A2026 coverage 0.9722 < 0.98**（216 完成場中 6 場無 published build；§6）。
4. **1-3 局帶系統性惡化**：base \|pred−actual\| 0.1pt（0.5336 vs 0.5346，近乎完美）→
   beta 校準後 2.6pt（0.5088 vs 0.5346），惡化 +2.5pt > 2pt 硬性上限（isotonic 同向 +2.3pt）。

揭露（不進判定）：4-6 帶惡化 +1.0pt（base 0.2pt → 1.2pt）；7-9 帶輕微改善方向不一
（base 0.1pt → 0.9pt，Brier 微改善 0.08515→0.08433）；10+ 帶（n=1,157，2024+ 突破僵局，
樣本小僅揭露）base 1.4pt → 4.0pt。

通過項：池化十分位 v2 閘門（0 顯著分箱）；每季 Brier 皆大勝主場常數基準；2023–25 coverage 1.0。

## 5. 失效機制：校準修正的時間非平穩性（本卡核心發現）

四個驗證季的 beta 參數幾乎不動（b 1.43–1.52、c −0.43~−0.54、a 0.93–1.05）：校準器學到的是
一個**恆定的「中心下修 + 兩端外擴」**修正，例如 p=0.55 → 0.51。它從何而來、為何過時：

1. **來源**：校準窗被 2021–22 wf 對主導（最深窗中仍佔 37%）。那兩季的 base 模型只見過
   2018–20（主隊勝率 0.562），對 2021–22（0.52–0.54）系統性高估主隊——WP-VAL1 §1 歸因的
   主場優勢漂移。校準器忠實學到「往下修」。
2. **過時**：2023+ 驗證季的 base 模型窗已含 2021+ 資料，漂移已被 base 自我吸收——證據是
   base 池化 1-3 局帶 dev 僅 −0.1pt（早局 WP ≈ 賽前基準率，直接反映主場先驗的正確性）。
   套上過時的下修 → 早局帶被推離真值 2.5pt。**wf 預測-結果對不是同分布樣本**：每季的對
   來自不同代 base 模型（窗長 3→7 季），其誤差剖面隨窗長系統性變化，池化擬合出的
   全域修正對「當前代」模型是錯的。
3. **梯度**：受益程度隨「與過時窗的距離」遞減——2025 大幅受益（ECE 0.026→0.012）、
   2024 受益、2023 打平、2026（base 已是全窗最佳校準，ECE 0.0198）被淨傷害。
4. **對照族一致**：isotonic 與 beta 在全部門檻上同向（2023/2026 Brier 同劣化、1-3 帶同惡化
   +2.3/+2.5pt）——失效來自訓練資料的結構，不是函數族或實作選擇。

方法論注記：分箱層級指標（池化 ECE、十分位）對此失效**幾乎無感**（校準後池化指標全數變好），
因為十分位混合了各局數；逐局帶診斷（卡面紅線 5，預先註冊）才把「早局被系統性推離」暴露出來。
WP-VAL1 證明「同母體評估看不到時間外失效」，本卡再加一層：**時間外池化分箱評估也看不到
按局數異質的失效**，兩者共同支持 recap 產品線「不得只用聚合指標自我驗證」的紀律。

## 6. 覆蓋與排除帳（fail-closed 對帳）

- 2023–2025 coverage 全 1.0；排除帳與 WP-VAL1 逐位一致（truncated 59–126/季、non_pa
  僅 2024+、unreliable 0）。
- **2026 coverage 0.9722**：完成 216 場，published canonical build 僅覆蓋 210 場；缺口為
  2026-07-24/25 的 6 場（sno 217–222），即最近一次 `cpbl-build-pa` 之後才完成的比賽。
  與 WP-VAL1 查核（Gemini）INFO finding 同源同口徑。**這是資料工程新鮮度缺口，
  非校準層或 base 模型缺陷**；本卡 db_scope=read 不得執行 build 修復。coverage 門檻
  fail closed 如實計入硬性失敗，但即使補跑 build 後 coverage 回 1.0，§4 的失敗 2/4
  仍獨立成立，不改變 No-Go 結論。
- 校準訓練窗使用 2021–22 wf 對各 23,000/22,847，全部驗證季校準窗樣本 ≥45,847 ≥
  `min_cal_pairs=5000` 下限。

## 7. 後續路徑（供規劃；本卡不裁定）

1. **季末重跑不足以翻案**：補跑 `cpbl-build-pa` + 季末重跑只解 coverage 一條；
   1-3 帶惡化與 2026 Brier 劣化是結構性的，預期不隨樣本補齊消失。
2. **校準窗設計變體**（recency 窗/衰減加權/逐局帶條件化校準）或可繞過非平穩性，但屬
   新設計：須另卡預註冊選窗準則（仍不得以驗證季表現挑選），不得在本卡內事後嘗試。
   注意逐局帶條件化會放大小樣本問題（10+ 帶單季 n=135–486）。
3. **WP-VAL1 §7 路徑 2（戰力感知）不受本卡影響**，仍是治本方向：領先持續性低估
   （高分箱結構性偏差）本來就不是事後校準能治的（本卡池化 bin 7 修正靠的是同時押低
   全域中心，代價即早局帶）。
4. 產品過渡決策同 WP-VAL1 §7 第 5 點，仍待需求方裁定。
