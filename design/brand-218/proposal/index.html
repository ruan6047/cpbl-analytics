Impeccable 評析與參考案例實際影響的決定

  • A 設計評析：首頁只留一個資料同步時間；例外狀態（今日無賽、延賽、開打時間缺值、球場缺值）畫成樣本；比分收斂成單一元件；選手頁三圍不重複、雷達與走勢不留空框、手機改單欄；賽況頁補 tabpanel、修正示意標示錯位。
  • B detector：郵戳對比、統一 icon 對比兩項修正；cream-palette 判誤報（暖灰紙是需求方指定）；字標副標 10.5px 列例外。
  • 未採用：評析建議的逐列「終／勝」與兩種比分候選——核定規劃改為「圖示：比分快速辨勝，文字放元件級或 aria」。
  • WebDesignClip 3 案例（沿用 discussion.html 已記錄的案例，本輪未重新抓取）：パ・リーグ仕事図鑑 → 只用少量棒球物件圖形（郵戳、票根）；Fencing Visualized → 單一強調色的資料可信感（PR 條只有一色，石油藍只標 PR 90 以上）；バファローズってなんなん？ → 活力只放在手札一句註記，不引入照片密度。
